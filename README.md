One newspaper front page that sums up Friday 20 November 2026: 38 dated, sourced stories from 6 continents in a single 1024×1024 image. The leads are Russia's massive overnight strike on Kyiv hours after the Shenzhen trilateral summit, and the Trump–Putin–Xi talks themselves; below them, the World Court's Rohingya genocide verdict against Myanmar, Anthropic's 34% Wall Street debut near a $2 trillion valuation, and COP31's final day, followed by regional briefs from Europe, Asia-Pacific, North America, Africa, the Middle East, South America and Oceania. The page was drawn with a Python/PIL program from that day's reporting (Reuters, AP, CNN, Le Monde, PANA and others); the repository holds the finished image and `main.ts` copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
